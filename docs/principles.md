# Principles

`agent-progress-ui` is built around nine product principles for long-running AI work:

1. Do not disguise long tasks as ordinary loading.
2. Show a plan before showing deep execution.
3. Bind motion to real events instead of decorative loops.
4. Let users leave the current page without losing the task.
5. Prefer named stages to fake precision.
6. Use different visual languages for executing, waiting, and review.
7. Keep control surfaces explicit for high-risk work.
8. Optimize for parallelism, not forced waiting.
9. End in a reviewable state before claiming full completion.

These principles are expanded in the original Chinese research source: [AI 长任务加载动画方案](./zh/AI%20%E9%95%BF%E4%BB%BB%E5%8A%A1%E5%8A%A0%E8%BD%BD%E5%8A%A8%E7%94%BB%E6%96%B9%E6%A1%88.md).
