# Scenarios

The repository currently ships three scenario packs:

## Chat

- Best for sub-15-second answer flows.
- Keeps the UI compact and warm.
- Starts streaming or drafting as quickly as possible.

## Research

- Best for evidence-heavy synthesis.
- Shows source discovery, retries, and draft artifacts.
- Uses `ready_for_review` to surface a draft before final export.

## Agent

- Best for multi-minute task execution.
- Displays tool runs, artifacts, checkpoints, and background handoffs.
- Treats the UI as a workbench rather than a loading panel.
